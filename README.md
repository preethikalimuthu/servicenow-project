# ServiceNow Project - Branch Wise Security (ACL)

**Team ID:** Preethikalimuthu
**Project:** servicenow-project

### Project Description
This project implements Branch-wise data security in ServiceNow using Access Control Lists (ACL).
Only users with bb1 role can see EEE department records.

### Milestones
- Milestone-1: Creation of Users and Roles (bb1, bb2)
- Milestone-2: Tables Creation (u_institution_details table with Branch field)
- Milestone-3: ACL READ - Branch is EEE
- Milestone-4: ACL CREATE
- Milestone-5: ACL WRITE
- Milestone-6: ACL DELETE
- Milestone-7: Conclusion & Testing with Impersonation
